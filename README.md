# AURA Luxury Beauty Landing (Static)

This is the first complete implementation of the AURA homepage based on the project brief in idea.md.

## Tech
- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure
- index.html
- css/base.css
- css/components.css
- css/sections.css
- js/main.js
- js/slider.js
- materials/
- video.mp4

## Run Locally
1. Open index.html directly in a browser.
2. For best media behavior, run a local static server.

Example with Python:
python3 -m http.server 8080

Then open:
http://localhost:8080

## Implemented Sections
- Fullscreen hero video using video.mp4
